# Evolution Group — фирменный reel

Стиль снят замерами с двух готовых роликов бренда, а не на глаз. Все числа
ниже воспроизведены и проверены на рендере (см. «Проверка»).

## Спецификация

| Параметр | Значение | Как измерено |
|---|---|---|
| Кадр | 1080×1920, 30 fps | оба референса |
| Длительность | 8–11 с | 7.9 с и 10.9 с |
| Монтаж | один непрерывный проход камеры, склеек нет | детектор склеек не нашёл ни одной при пороге 0.25 |
| Заголовок | Playfair Display Regular, 113 px | посимвольный IoU 0.83 с референсом |
| — цвет | чистый белый, без тени и подложки | |
| — трекинг | +2 px на просвет | ширина набора 634 px против 620 px без трекинга |
| — позиция | центр кадра: x 540, y 966 | высота прописной 80 px |
| — тайминг | появление 0.35 с, уход к 3.80 с | фейд 0.15 с на входе, 0.35 с на выходе |
| Плашка бренда | 277×77 px, x = 38, 42 px от низа | |
| Затемнение | 0.55 с в хвосте, до чёрного | |
| Музыка | сплошная подложка ~89 BPM, звук камеры не слышен | MFCC-сходство двух роликов 0.975 — трек один |

Расхождение между референсами: во втором ролике плашка мельче (254×70, x = 50,
70 px от низа) и нет ни заголовка, ни затемнения. За канон взят вариант с
заголовком; остальное — параметры скрипта.

## Как собрать

```bash
python3 .claude/skills/evolution-reel/scripts/make_reel.py \
    /path/to/clip1.mov /path/to/clip2.mov \
    --title BATHROOM \
    --music /path/to/track.mp3 \
    -o edit/final.mp4
```

Полезные ключи:

- `--trim 2.4:9.1` — по одному на каждый исходник, в том же порядке.
- `--draft` — 720p ultrafast, чтобы быстро посмотреть точки склейки.
- `--no-badge` — если плашка уже вшита в исходник.
- `--no-end-fade` — для ролика в середине серии.
- `--keep-source-audio` — подмешать звук камеры под музыку на −12 dB.
- `--title-in` / `--title-out` — сдвинуть окно заголовка.

Скрипт приводит каждый исходник к 1080×1920 (scale + crop по большей
стороне), склеивает без перекодирования, накладывает заголовок и плашку,
затемняет хвост и нормализует громкость до −14 LUFS.

## Согласование клипов между собой

Съёмка с разных дублей не совпадает по яркости и контрасту, и на склейке это
видно. Порядок такой: выбрать самый удачный клип за эталон, замерить у него
среднюю яркость, разброс яркости и перевес R−B, затем подогнать остальные
через `--grade` — по одной цепочке на исходник, в том же порядке, что и сами
исходники.

Опорные числа фирменного стиля (из референса): яркость ~120, разброс ~48,
R−B ~+10.

Пример с реального объекта (ванная с мрамором, орехом и золотом, съёмка DJI):

```
--grade "eq=contrast=1.05:brightness=0.005:saturation=1.02"
--grade "eq=contrast=1.30:brightness=-0.005:saturation=1.20,colortemperature=temperature=5200:mix=0.55"
--grade "eq=contrast=1.45:brightness=-0.046:saturation=1.55,colortemperature=temperature=5200:mix=0.55"
```

После рендера проверять стык: замерить яркость за 0.1 с до склейки и через
0.1 с после. Разбег больше ~15 единиц виден глазом.

Звук с дрона и с камеры — мусор (в этом материале от −65 до −31 dB, только
шум обдува). Ставить `--mute` и класть музыку отдельно.

## Рабочий порядок

1. Посмотреть исходники: `ffprobe`, затем `timeline_view.py` из скилла
   `video-use` на спорных участках.
2. Предложить раскадровку словами — какие куски, в каком порядке, какой
   заголовок. Дождаться подтверждения.
3. Собрать `--draft`, показать, поправить.
4. Финальный рендер, отдать файл.

Заголовок — одно слово заглавными, по названию помещения: BATHROOM, KITCHEN,
LIVING ROOM. В референсах он стоит только на первом ролике серии.

## Ассеты

- `assets/badge_evolution_group.png` — плашка, вырезана из кадра референса

## Грабли ffmpeg, на которые уже наступили

`overlay` синхронизирует потоки по меткам времени, и картинка-оверлей на этом
ловит две противоположные ошибки сразу:

- Одиночный кадр (`-i badge.png` без `-loop`) держится за счёт повтора
  последнего кадра — и этот повтор перестаёт работать после того, как
  закончился предыдущий оверлей в цепочке. Плашка молча исчезала с середины
  ролика.
- Картинка ровно той же длины, что и основное видео, даёт обратный эффект:
  `overlay` дотягивает хвост, и в ролик приезжает несколько секунд чёрного.

Рабочая комбинация: оверлей заголовка с `eof_action=pass` (после конца
заголовка основное видео идёт насквозь), плашка длиннее картинки на секунду
плюс `shortest=1` на её `overlay` (цепочка кончается вместе с основным видео).
Проверять после каждой правки числом кадров, а не на глаз.
